# Product Inventory Manager
## Project Description
The Product Inventory Manager is Javascript program designed to help a small shop manage its products and stock.
The program stores product information, calculates the stock value of each product, calculates the total inventory value, and identifies products that need restocking. The inventory reportis displayed in the browser Console.
## Features
- stores multiple products using an array of objects.
- Records product IDs, names, prices, and quantities.
- Calculates the stock value of each product.
- Calculates the total inventory value.
- Identifies low-stock products.
- Identifies products that are out of stock.
- Uses loops to process product records.
- Uses reusable functions.
- Uses filter(),find(),and map().
- Includes testing with console.assert().
- Displays a readable inventory report in the browser Console.

## Concepts Demonstrated
This project demonstrates variables, data types, arithmetic operators, conditions, loops, functions, arrays, objects, debugging, and testing.
## Low-Stock Rule
A product is considered low stock when its quantity is 5 units or less.
A product with zero units is identified as out of stock.
## Inventory Calculations
The stock value of each product is calculated as:
stock value = Price per Unit * Quantity in Stock
The total inventory value is the sum of all product stock values.
